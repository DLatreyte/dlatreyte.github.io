Bilan quantitatif des transformations chimiques

Évolution d’un système chimique

Info

Un système évolue chimiquement s’il existe (au moins) une réaction chimique en son sein. Cette réaction chimique nécessite la présence de réactifs — espèces chimiques capables de réagir entre elles — et s’effectue selon les proportions données par les nombres stœchiométriques qui apparaissent dans l’équation de la réaction. Il se forme alors un ou plusieurs produits, dans les proportions données par les nombres stœchiométriques.

Info

Un système chimique évolue tant que les quantités de matière des réactifs (et donc des produits) changent macroscopiquement.
L’évolution d’un système chimique peut conduire à deux situations différentes :

  • Dans l’état final, au moins un des réactifs a disparu : la transformation chimique est alors dite totale.

  • Dans l’état final, aucun des réactifs n’a totalement disparu mais le système chimique a atteint un état d’équilibre chimique : la transformation chimique est alors dite limitée et l’état final est un état d’équilibre.

Mélange dans les proportions stœchiométriques

À retenir

Un mélange de réactifs, dans l’état initial, est dit dans les proportions stœchiométriques si les quantités de matière (initiales donc) de ces réactifs respectent les proportions données par les nombres stœchiométriques.

Exercice 1. Réaction du monoxyde de carbone et du dioxygène

Le monoxyde de carbone CO\ce{CO}CO peut réagir avec le dioxygène pour former du dioxyde de carbone.

  1. Écrire l’équation de cette réaction en utilisant les nombres stœchiométriques entiers les plus petits possibles.

    Réponse
    CO(g)+12 OX2(g) −→COX2(g)\ce{ CO (g) + 1/2 O2 (g) --> CO2 (g) }CO(g)+21​OX2​(g) −​COX2​(g)

    donc

    2 CO(g)+OX2(g) −→2 COX2(g)\ce{ 2 CO (g) + O2 (g) --> 2 CO2 (g) }2CO(g)+OX2​(g) −​2COX2​(g)

  2. Quelle quantité de matière de dioxygène est nécessaire pour faire réagir 2 moles de monoxyde de carbone ? Pour faire réagir 6 moles de monoxyde de carbone ?

    Réponse

    D’après l’équation de la réaction,

    n(CO)qui reˊagitn(OX2)qui reˊagit=21  ⟺  n(OX2)qui reˊagit=12n(CO)qui reˊagit\dfrac{n(\ce{CO})_{\text{qui réagit}}}{n (\ce{O2})_{\text{qui réagit}}} = \dfrac{2}{1} \iff n (\ce{O2})_{\text{qui réagit}} = \dfrac{1}{2} n(\ce{CO})_{\text{qui réagit}}n(OX2​)qui reˊagit​n(CO)qui reˊagit​​=12​⟺n(OX2​)qui reˊagit​=21​n(CO)qui reˊagit​

    A.N. n(OX2)qui reˊagit=12×2 mol=1 moln (\ce{O2})_{\text{qui réagit}} = \dfrac{1}{2} \times \pu{2 mol} = \pu{1mol}n(OX2​)qui reˊagit​=21​×2 mol=1 mol.

    Pour faire réagir 2 mol\pu{2 mol}2 mol de monoxyde de carbone, il faut 1 mol\pu{1 mol}1 mol de dioxygène. On voit immédiatement qu’il faut 3 mol\pu{3 mol}3 mol de dioxygène pour faire réagir 6 mol\pu{6 mol}6 mol de monoxyde de carbone.

  3. Quelle quantité de matière de dioxyde de carbone obtient-on lorsqu’on fait réagir 3 moles de monoxyde de carbone ?

    Réponse

    D’après l’équation de la réaction,

    n(CO)qui reˊagitn(COX2)qui se forme=22=1  ⟺  n(COX2)qui se forme=n(CO)qui reˊagit\dfrac{n(\ce{CO})_{\text{qui réagit}}}{n (\ce{CO2})_{\text{qui se forme}}} = \dfrac{2}{2} = 1 \iff n (\ce{CO2})_{\text{qui se forme}} = n(\ce{CO})_{\text{qui réagit}}n(COX2​)qui se forme​n(CO)qui reˊagit​​=22​=1⟺n(COX2​)qui se forme​=n(CO)qui reˊagit​

    A.N. n(COX2)qui se forme=3 moln (\ce{CO2})_{\text{qui se forme}} = \pu{3 mol}n(COX2​)qui se forme​=3 mol

  4. Déterminer l’expression littérale indiquant quelles sont « les proportions données par les nombres stœchiométriques » pour la réaction étudiée dans cet exercice.

    Réponse
    n(CO)qui reˊagit2=n(OX2)qui reˊagit1=n(COX2)qui se forme2\dfrac{n(\ce{CO})_{\text{qui réagit}}}{2} = \dfrac{n (\ce{O2})_{\text{qui réagit}}}{1} = \dfrac{n (\ce{CO2})_{\text{qui se forme}}}{2}2n(CO)qui reˊagit​​=1n(OX2​)qui reˊagit​​=2n(COX2​)qui se forme​​

On considère la combustion complète du propane CX3HX8\ce{C3H8}CX3​HX8​ dans l’air.

Transformation chimique totale

À retenir

Une transformation chimique est totale si, dans l’état final, au moins un des réactifs a disparu.
Ce réactif est alors appelé réactif limitant.

À retenir

On appelle avancement maximal xmaxx_{\text{max}}xmax​ l’avancement final d’une transformation chimique totale :

xf=xmax  ⟺  la transformation chimique est totalex_f = x_{\text{max}} \iff \text{la transformation chimique est totale}xf​=xmax​⟺la transformation chimique est totale
