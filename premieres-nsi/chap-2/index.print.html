Objectif

Comment représenter une information dans un programme ?

L’informatique consiste à automatiser le traitement d’informations. Pour effectuer ces traitements, un programme doit d’abord être capable de représenter les informations issues du monde réel.

Un âge, une température, un nom, une réponse à une question ou une distance ne sont pas des informations de même nature. Un langage de programmation utilise donc différents types pour modéliser ces différentes informations.

Q31.

Pour chacune des informations suivantes, proposer une manière simple de la représenter à l’aide de Python :

  • le nombre d’élèves d’une classe ;
  • une température de 18,5 °C ;
  • le nom d’un élève ;
  • la réponse à la question « l’élève est-il majeur ? ».

Tester ensuite dans la console :

>>> type(32)
>>> type(18.5)
>>> type("Alice")
>>> type(False)

Quels sont les quatre réponses obtenus ?

Réponse

On obtient :

>>> type(32)
<class 'int'>
>>> type(18.5)
<class 'float'>
>>> type("Alice")
<class 'str'>
>>> type(False)
<class 'bool'>

On utilise int pour représenter un entier relatif, float pour un nombre flottant, str pour du texte et bool pour une information logique.

Le choix d’un type constitue donc une première étape de modélisation d’une information réelle.

À retenir

Un programme manipule des représentations d’informations. Le type précise la nature des valeurs manipulées et détermine les opérations que Python pourra leur appliquer.

Q46.

Lancer le programme en mode débogage puis utiliser la touche F7. Relever les valeurs successives prises par chacun des deux arguments avant que la fonction max ne soit appliquée. Que peut-on en conclure sur la nature d’un argument ?

Réponse

Thonny évalue d’abord séparément chaque argument : 2 + 3 devient 5 et 4 * 2 devient 8. L’appel se ramène alors à max(5, 8), qui retourne 8.

Un argument est une expression : Python la réduit à une valeur avant d’effectuer l’appel de la fonction.

Q47.

Prévoir la valeur de chacune des expressions suivantes, puis les écrire dans la partie principale de l’éditeur Thonny :

round(math.sqrt(50), 1)
max(abs(-10), round(7.4))

Il sera peut être nécessaire de rechercher à l’aide de la fonction help l’action de chacune des fonctions qui doivent être utilisées.

Lancer le programme en mode débogage puis utiliser la touche F7. Pour chaque expression, indiquer quelle fonction est appelée en premier, quelle valeur elle retourne, et comment cette valeur est ensuite utilisée.

Réponse

Dans round(math.sqrt(50), 1), Python évalue d’abord math.sqrt(50), qui retourne environ 7.071. Cette valeur devient le premier argument de round : l’appel se ramène à round(7.071, 1), qui retourne 7.1.

Dans max(abs(-10), round(7.4)), les deux arguments sont d’abord évalués : abs(-10) retourne 10 et round(7.4) retourne 7. L’appel devient max(10, 7), qui retourne 10.

La valeur retournée par une fonction peut donc servir d’argument à une autre fonction : c’est la composition de fonctions.

À retenir

Appeler (ou utiliser) une fonction, c’est écrire son nom suivi de parenthèses contenant ses arguments, séparés par des virgules : round(3.14159, 2).

  • Une fonction reçoit zéro, un ou plusieurs arguments et retourne une valeur après avoir effectué un traitement.
  • Chaque argument est une expression : Python l’évalue d’abord, puis effectue l’appel.
  • La valeur retournée peut être réutilisée, en particulier comme argument d’une autre fonction : math.sqrt(abs(3 - 12)).
  • Le nom d’une fonction ne suffit pas pour savoir l’utiliser : on consulte sa documentation avec help.
  • Des fonctions supplémentaires sont regroupées dans des modules, chargés avec import puis utilisés avec la syntaxe module.nom.

Q54.

Définir :

def somme(x: float, y: float, z: float) -> float:
    """Retourne la somme de x, y et z."""
    return x + y + z

Puis compléter :

À retenir

Définir une fonction, c’est décrire une fois pour toutes le traitement qu’elle réalise, pour pouvoir ensuite l’appeler autant de fois que nécessaire.

def moyenne(a: float, b: float, c: float) -> float:
    """Retourne la moyenne de a, b et c."""
    return (a + b + c) / 3
  • On commence par le mot-clé def, suivi du nom de la fonction.
  • Entre parenthèses, on liste les paramètres, chacun annoté par son type (a: float). Après ->, on annonce le type de la valeur retournée.

  • La documentation (chaîne entre triples guillemets) décrit ce que fait la fonction.
  • return indique la valeur retournée par la fonction, puis met fin à son exécution.
  • Le corps d’une fonction peut appeler d’autres fonctions, déjà définies ou fournies par Python.

Définir la fonction polynomiale qui reçoit les arguments a, b, c, d, x et qui retourne le résultat du calcul ax3+bx2+cx+da x^3 + b x^2 + c x + dax3+bx2+cx+d.

Réponse
  • False and (1 / 0) : Python sait déjà que le résultat est False dès qu’il lit False ; il n’évalue pas 1 / 0. Aucune erreur.
  • True or (1 / 0) : Python sait déjà que le résultat est True dès qu’il lit True ; il n’évalue pas 1 / 0. Aucune erreur.

Évaluation en court-circuit

Python évalue toujours une expression de gauche à droite, mais s’arrête dès que le résultat est déterminé, sans évaluer le reste :

  • avec and, si le premier opérande vaut False, le second n’est pas évalué (le résultat est déjà False) ;
  • avec or, si le premier opérande vaut True, le second n’est pas évalué (le résultat est déjà True).

Q51.

Objectif

En manipulant les boucles for et while dans la console et dans Thonny, vous allez apprendre à répéter des instructions un nombre de fois connu ou inconnu à l’avance, et à choisir la structure itérative adaptée à chaque situation.

Combien de fois une instruction doit-elle être répétée ?

Un programme est souvent amené à répéter plusieurs fois les mêmes instructions : afficher les nombres de 1 à 1000, demander un mot de passe jusqu’à ce qu’il soit correct, ou additionner les notes d’une classe entière. Écrire autant de fois l’instruction à répéter serait absurde ; les langages de programmation proposent pour cela des structures itératives, plus couramment appelées boucles. Chaque passage dans une boucle est appelé une itération.

À retenir
  • Une boucle déterministe (ou boucle Pour) répète un nombre d’itérations connu à l’avance ; elle utilise une variable, le compteur de boucle, pour compter les itérations effectuées.
  • Une boucle non déterministe (ou boucle conditionnelle) répète des itérations tant qu’une condition d’arrêt n’est pas vérifiée ; ce nombre n’est pas connu à l’avance.

Python ne fournit qu’une seule boucle non déterministe, la boucle while (Tant que). Une boucle non déterministe peut toujours remplacer une boucle déterministe ; l’inverse n’est pas vrai.

La boucle “Tant que” : l’instruction while

Syntaxe et fonctionnement

La syntaxe d’une boucle while est :

while <condition>:
    instructions à répéter

La condition est une expression booléenne, évaluée au début de chaque itération. Tant qu’elle vaut True, le bloc indenté est exécuté, puis la condition est évaluée à nouveau. Dès qu’elle vaut False, la boucle s’arrête et l’exécution reprend après le bloc. Il est même possible que le bloc ne soit exécuté aucune fois, si la condition est déjà fausse dès la première évaluation.

Boucle infinie

Si aucune instruction du bloc ne fait progresser la condition vers sa fin (si, par exemple, i += 1 avait été oublié), la condition i <= n resterait indéfiniment vraie : la boucle s’exécuterait sans jamais s’arrêter. Ce défaut porte un nom : la boucle infinie.

À retenir

Écrire une boucle while suppose de réunir trois éléments :

  1. une initialisation de la ou des variables testées par la condition ;
  2. une condition d’arrêt, expression booléenne évaluée avant chaque itération ;
  3. une instruction qui fait progresser cette condition à chaque itération, jusqu’à ce qu’elle devienne fausse.

Oublier ce troisième élément est la cause la plus fréquente de boucle infinie.

La boucle “Pour chaque” : l’instruction for et l’itérateur range

Syntaxe de la boucle “Pour chaque”

En Python, l’instruction for implémente en réalité une boucle Pour chaque : elle parcourt, un par un, les éléments d’un objet itérable, et non un simple compteur comme dans d’autres langages.

for element in itérable:
    instructions à répéter

À chaque itération, la variable element prend la valeur de l’élément courant de l’itérable, pour être utilisée dans le bloc indenté. Cette variable ne doit jamais être modifiée dans le corps de la boucle : dans le cas contraire, le comportement de la boucle devient imprévisible.

L’itérateur range

L’itérateur range génère, à la volée, des entiers compris entre une valeur de départ début et une valeur finale fin (exclue), par pas de pas. Trois écritures sont possibles :

range(fin) entiers de 0 à fin (exclu), par pas de 1
range(début, fin) entiers de début à fin (exclu), par pas de 1
range(début, fin, pas) entiers de début à fin (exclu), par pas de pas

Comme pour les tranches, la valeur fin n’est jamais atteinte : Python considère systématiquement les intervalles sous la forme [deˊbut,fin[[\text{début}, \text{fin}[[deˊbut,fin[.

L’instruction break

break met fin immédiatement à la boucle en cours et poursuit l’exécution juste après elle. On l’utilise généralement lorsqu’une condition testée avec if doit provoquer une sortie immédiate de la boucle. break s’utilise aussi bien dans une boucle for que dans une boucle while ; elle est en particulier indispensable pour sortir d’une boucle délibérément infinie, écrite avec while True:.

continue interrompt seulement l’itération courante et reprend au début de l’itération suivante : nouvelle évaluation de la condition pour une boucle while, élément suivant pour une boucle for.

moyenne_ter et devine ne peuvent pas être réécrites avec for : le nombre d’itérations (le nombre de notes saisies, le nombre de tentatives) n’est pas connu avant l’exécution. Seule une boucle while permet d’arrêter une boucle sur un événement imprévisible.

À retenir

Le choix entre for et while dépend de la nature du problème, pas des préférences du programmeur :

  • si le nombre d’itérations est connu avant l’exécution (un nombre de termes, une taille fixée), for est le choix naturel et le plus lisible ;
  • si ce nombre dépend du déroulement de l’exécution (une saisie jusqu’à une valeur correcte, une recherche jusqu’à un résultat), seule une boucle while convient.

Objectif

Constantes

Une variable dont la valeur ne change pas pendant l’exécution du programme est appelée une constante. Par convention, en Python, son nom s’écrit en majuscules (LARGEUR, TAILLE_JOUEUR). Variables locales et variables globales
  • Une variable définie en dehors de toute fonction est une variable globale. Toute fonction peut lire sa valeur.
  • Une variable qui reçoit une valeur à l’intérieur d’une fonction est une variable locale à cette fonction.
  • Pour qu’une fonction puisse modifier une variable globale, il faut écrire global nom_de_la_variable au début du corps de la fonction.
