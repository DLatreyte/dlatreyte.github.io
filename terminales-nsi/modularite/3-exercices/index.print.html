import math


def terme(k: int) -> float:
    return 1 / (k**2)


def approxpi(n: int) -> float:
    s = 0.0
    # utilise les termes jusqu'à 1/n**2 inclus
    for k in range(n):
        s = s + terme(k)
    return math.sqrt(s * 6)

import random


def scalaire(v1: tuple[int, ...], v2: tuple[int, ...]) -> int:
    """
    Calcule le produit scalaire des deux vecteurs v1 et v2.
    """
    s = 0
    for k in range(len(v1)):
        s = s + v1[k] * v2[k]
    return s


def random_vect(n: int) -> tuple[int, ...]:
    """
    Génère un vecteur de taille n contenant des entiers non nuls
    entre -10 et 10
    """
    v: list[int] = []
    for _ in range(n):
        val = random.randint(-10, 10)
        if val != 0:
            v.append(val)
    return tuple(v)


def main() -> None:
    for _ in range(20):
        print(scalaire(random_vect(3), random_vect(3)))


if __name__ == "__main__":
    main()

Calculer la valeur d’un mot : arithmancie

On souhaite associer une valeur numérique à une chaîne de caractères. La valeur associée à la chaîne est la somme des valeurs associées à chacun des caractères qui la composent. Aux lettres non accentuées de A à Z, qu’elles soient en minuscules ou en majuscules, on associe leur numéro d’ordre dans l’alphabet, de 1 à 26. À tous les autres symboles (lettres accentuées, chiffres, espaces, ponctuations), on associe la valeur 0.
On rappelle que ord("a") donne le code numérique associé à la lettre "a" passée en paramètre. La chaîne string.ascii_uppercase est définie dans le module string et vaut "ABCDEFGHIJKLMNOPQRSTUVWXYZ".

  1. Pour chacune des propositions suivantes, proposer un test qui montre que la fonction ne répond pas au cahier des charges de l’énoncé.

Proposition 1

def valeur1(chaine: str) -> int:
    s = 0
    for c in chaine:
        if c >= "A" and c <= "Z":
            s = s + ord(c) - ord("A") + 1
    return s

Proposition 2

def valeur2(chaine: str) -> int:
    s = 0
    for c in chaine.upper():
        if c >= "A" and c < "Z":
            s = s + ord(c) - ord("A") + 1
    return s

Proposition 3

import string


def valeur3(chaine: str) -> int:
    s = 0
    for c in chaine.upper():
        if c in string.ascii_uppercase:
            s = s + string.ascii_uppercase.index(c)
    return s

  1. Proposer un ensemble complet de tests pour la fonction que l’on veut créer (on nomme cette fonction valeur).

  2. Proposer le code de cette fonction (il est possible de s’inspirer d’une des versions vues à la question 1. en la corrigeant). Ne pas oublier de vérifier que la fonction écrite passe bien les tests de la question 2.

Coup de pouce

Pour la question 1, regarder chaque proposition ligne par ligne en se demandant : que se passe-t-il pour une lettre minuscule ? pour la lettre "Z" ? pour la lettre "A" ? Un bon test est un cas où l’on sait calculer à la main la valeur attendue.

Module d’arithmétique

Créer un module contenu dans un fichier nommé arithmetique.py. Ce module contient des fonctions sur l’arithmétique des nombres entiers. En particulier :

  • expo qui prend en paramètres les entiers aaa, bbb et nnn et calcule le reste de la division par nnn de aba^bab ;
  • pgcd qui prend en paramètres les entiers aaa et bbb et renvoie le plus grand diviseur commun de aaa et bbb (définition du pgcd) ;
  • decomposition qui prend un entier n⩾2n \geqslant 2n⩾2 en paramètre et renvoie la liste de ses facteurs premiers ainsi que leur multiplicité, sous la forme d’une liste de tuples (facteur, multiplicité).
  1. Créer le module avec les trois fonctions proposées.
  2. Proposer des docstrings pour le module et les trois fonctions décrites. Annoter les fonctions avec les annotations de type.
  3. Ajouter quelques tests sous forme d’assertions.

Algorithme naïf pour la fonction decomposition

La première idée consiste à balayer la liste des nombres premiers en testant si le nombre premier ppp divise nnn. Si oui, on recommence l’algorithme pour n//pn//pn//p, en ne testant que les diviseurs premiers encore envisageables. On s’arrête quand le nombre premier à tester devient supérieur à la racine carrée du nombre qu’il est censé diviser.
Ainsi pour décomposer 2088 en produit de facteurs premiers
2088 2 2 divise 2088, le quotient est 1044
1044 2 2 divise 1044, le quotient est 522
522 2 2 divise 522, le quotient est 261
261 3 2 ne divise pas 261, mais 3 divise 261 et le quotient est 87
87 3 3 divise 87 et le quotient est 29
29 ni 3, ni 5 ne divisent 29 et 727^272 est plus grand que 29 (fin)

On obtient la décomposition attendue : 2088=23×32×292088=2^3 \times 3^2 \times 292088=23×32×29.

Coup de pouce

Pour expo, calculer aba^bab puis le reste de la division par nnn fonctionne, mais aba^bab devient vite énorme. On peut prendre le reste à chaque multiplication : le reste de x×ax \times ax×a ne dépend que du reste de xxx. Pour decomposition, il n’est pas nécessaire de connaître la liste des nombres premiers : si l’on teste les diviseurs dans l’ordre croissant en divisant nnn autant de fois que possible, chaque diviseur trouvé est forcément premier.
