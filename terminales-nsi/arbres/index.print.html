Structures de données abstraites arborescentes : les arbres

La notion de listes chaînées est parfaite pour structurer un ensemble d’élements destinés à être énumérés séquentiellement. Elle permet aussi d’implémenter les structures de piles et de files. Elle n’est cependant pas adaptée aux accès spécifiques à des positions données dans la séquence, puisqu’il faut alors parcourir toutes les cellules depuis le début de la liste jusqu’à la position souhaitée (complexité en O(N)O(N)O(N)).

Définitions et vocabulaire

Arbre (enraciné)

À retenir

  • Un arbre (nom complet arbre enraciné) est une structure de données abstraite arborescente dans laquelle les données sont hiérarchisées depuis un nœud racine.

  • Un arbre dont tous les nœuds sont nommés est dit étiqueté. L’étiquette (ou nom du sommet) représente la « valeur » du nœud ou bien l’information associée au nœud.

Racine, noeud, branche, feuille

À retenir
  • Un arbre est un ensemble organisé de nœuds dans lequel chaque nœud a un père, sauf un nœud que l’on appelle le nœud racine.
  • Si le nœud n’a pas de fils, on dit que c’est une feuille.
  • Les nœuds sont reliés par des branches.

Profondeur d’un nœud, hauteur d’un nœud

À retenir

La profondeur d’un nœud est sa distance à la racine.
La profondeur d’un nœud dans un arbre est donc le nombre d’arrêtes qu’il faut parcourir, depuis la racine, pour parvenir au nœud.

À retenir

La hauteur d’un nœud est sa distance à la feuille la plus profonde ayant une relation de descendance avec lui.
La hauteur d’un nœud dans un arbre est donc le nombre d’arrêtes qu’il faut parcourir, depuis ce nœud jusqu’à la feuille la plus profonde ayant une relation de descendance avec lui.

Profondeur d’un arbre

À retenir

La hauteur (ou profondeur) d’un arbre est égale à la profondeur du nœud le plus profond.

Info

La hauteur d’un arbre est très importante. En effet, la plupart des algorithmes que nous verrons dans la suite ont une complexité qui dépend de la hauteur de l’arbre. Ainsi plus l’arbre aura une hauteur élevée, plus l’algorithme mettra de temps à s’exécuter.

Avertissement

Tous les auteurs n’utilisent pas la convention choisie dans ce cours !
Pour certains, la profondeur d’un nœud est égale au nombre de nœuds qu’il faut parcourir à partir de la racine (incluse) pour parvenir au nœud ; la hauteur de la racine est alors de 1.

Les arbres binaires

Arbres binaires

Définition

À retenir

Un arbre binaire est une structure de données abstraite formée d’un ensemble de nœuds organisés hiérarchiquement selon la définition par récurrence suivante :

Un arbre binaire est :

  • soit un arbre vide, noté EEE, ne contenant aucun nœud ;
  • soit un nœud, appelé racine, relié à exactement deux arbres binaires ggg et ddd, respectivement appelés sous-arbres gauche et sous-arbre droit.

On note T(r,g,d)T(r,g,d)T(r,g,d) l’arbre non vide dont la racine rrr (on peut aussi indiquer l’étiquette de cette racine).

Vocabulaire et remarques

  • Un nœud dont les deux sous-arbres sont vides est appelé une feuille.
  • Un nœud qui n’est pas une feuille est un nœud interne.
  • Un arbre binaire est dit parfait si toutes les feuilles sont à la même profondeur.
  • La racine d’un arbre TTT est le seul nœud de TTT sans parent.

Propriétés

Position des sous-arbres
  • La position des sous-arbres gauche et droite est fondamentale : T(r,g,d)≠T(r,d,g)T(r,g,d) \neq T(r,d,g)T(r,g,d)=T(r,d,g)
Taille d’un arbre
  • La taille d’un arbre est égale au nombre de nœuds qu’il comporte.
  • Le nombre de nœuds d’un arbre binaire TTT, noté n(T)n(T)n(T), se calcule récursivement :
    • n(E)=0n(E)=0n(E)=0
    • n(T)=1+n(g)+n(d)n(T)=1+n(g)+n(d)n(T)=1+n(g)+n(d)
Profondeur d’un nœud
  • La profondeur d’un nœud nnn, notée h(n)h(n)h(n), est sa distance à la racine.
  • La profondeur d’un nœud nnn, notée h(n)h(n)h(n), est définie récursivement par :
    • h(racine)=0h(\text{racine})=0h(racine)=0
    • h(n)=1+h(parent de n)h(n)=1+h(\text{parent de }n)h(n)=1+h(parent de n)
  • La profondeur d’un nœud dans un arbre est donc le nombre d’arrêtes qu’il faut parcourir, depuis la racine, pour parvenir au nœud.
Avertissement

La définition de la profondeur d’un nœud peut varier ! Il est impératif de vérifier celle choisie avant tout travail.

Hauteur d’un arbre
  • La hauteur d’un arbre est la profondeur du nœud le plus éloigné de la racine.
    La hauteur d’un arbre est aussi sa profondeur.
  • La hauteur d’un arbre binaire TTT, notée h(T)h(T)h(T) est définie récursivement par :
    • h(E)=−1h(E)=-1h(E)=−1 si l’arbre est vide ;
    • h(T)=1+max(h(g),h(d))h(T)=1+\mathrm{max}(h(g), h(d))h(T)=1+max(h(g),h(d))

Remarque

On peut aussi définir la hauteur d’un nœud : la hauteur d’un nœud est la distance entre ce nœud et la feuille la plus profonde ayant une relation de descendance avec ce nœud.

Avertissement

La définition de la hauteur d’un arbre peut varier ! Il est impératif de vérifier celle choisie avant tout travail.

Relation entre le nombre de nœuds nnn et la hauteur d’un arbre

  • Soit TTT un arbre binaire, nnn son nombre de nœuds et hhh sa hauteur. Ces grandeurs sont liées par les relations suivantes :

  • h+1≤n≤2h+1−1h + 1 \leq n \leq 2^{h+1} - 1h+1≤n≤2h+1−1

  • le nombre de sous-arbres vides de TTT est n+1n+1n+1.

  1. Dans quel cas a-t-on N=h+1N = h+1N=h+1 ?

    Réponse

    On a N=h+1N = h+1N=h+1 lorsque chaque nœud ne possède qu’un seul nœud fils. Il s’agit donc d’une structure linéaire (liste).

  2. Dans quel cas a-t-on N=2h+1−1N = 2^{h+1} - 1N=2h+1−1 ?

    Réponse

    On a N=2h+1−1N = 2^{h+1} - 1N=2h+1−1 lorsque l’arbre binaire est parfait, c’est à dire lorsque toutes les feuilles ont la même profondeur.

Réponse 
def taille(n: Noeud) -> int:
    """
    Retourne le nombre de noeud dans l'arbre.
    """
    if est_vide(n):
        # Cas de base : un arbre vide ne contient aucun noeud.
        return 0
    else:
        # Recherche récursive dans les sous-arbres gauche et droit.
        taille_gauche = taille(n.gauche)
        taille_droit = taille(n.droit)

        # Calcul de la taille
        return 1 + taille_gauche + taille_droit

def profondeur(n: Noeud) -> int:
    """
    Retourne la profondeur de l'arbre.
    """
    if est_vide(n):
        # Cas de base : si le nœud est vide, il n'est pas dans l'arbre.
        return -1
    else:
        # Recherche récursive dans les sous-arbres gauche et droit.
        arbre_gauche = profondeur(n.gauche)
        arbre_droit = profondeur(n.droit)

        # Détermine la profondeur
        return 1 + max(arbre_gauche, arbre_droit)

def profondeur_noeud(n: Noeud, val: str, prof: int = 0) -> int:
    """
    Détermine la profondeur du noeud de valeur val.
    Retourne -1 si le noeud n'est pas dans l'arbre.

    prof est la profondeur.
    """
    if est_vide(n):
        # Cas de base : si le nœud est vide, il n'est pas dans l'arbre.
        return -1
    elif n.valeur == val:
        # On a trouvé le noeud
        return prof
    else:
        # Recherche récursive dans les sous-arbres gauche et droit.
        # Incrémente la profondeur
        prof_gauche = profondeur_noeud(n.gauche, val, prof + 1)
        prof_droite = profondeur_noeud(n.droit, val, prof + 1)

        # Valeur retournée
        return max(prof_gauche, prof_droite)

Arbres Binaires Recherche

Introduction

Info

Quelle structure de données permet :

  • d’organiser les données selon un ordre donné (numérique, lexicographique, etc.) ;
  • d’effectuer des recherches le plus efficacement possible ;
  • d’accéder à, d’insérer ou de supprimer les données le plus efficacement possible.

Tableaux

Propriétés
  • On peut ordonner des données dans un tableau mais l’algorithme de tri le plus rapide, pour un jeu de données aléatoires, est en O(n  log⁡n)O(n \; \log n)O(nlogn) ;
  • On peut accéder à une donnée en O(1)O(1)O(1) ;
  • On peut rechercher une valeur efficacement en utilisant la dichotomie (si le tableau est trié !) : O(log⁡n)O(\log n)O(logn) ;
  • Supprimer ou insérer une valeur n’est pas très efficace : O(n)O(n)O(n) (sauf à la fin du tableau).

Dictionnaires

Propriétés
  • Accéder à, supprimer et insérer une valeur se fait très efficacement : O(1)O(1)O(1) ;
  • Les données ne sont pas ordonnées.
Remarque
Dans la suite de ce document, on considérera que les valeurs des nœuds sont des entiers.
À retenir

Un arbre binaire de recherche, ou ABR, est un arbre binaire avec la propriété suivante : quel que soit le nœud xxx, tous les nœuds situés dans le sous-arbre gauche de xxx ont une valeur inférieure à la valeur du nœud xxx, et tous ceux situés dans son sous-arbre droit ont une valeur supérieure à la valeur du nœud xxx.

Remarque
La définition précédente est récursive.
