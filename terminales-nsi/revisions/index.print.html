Révisions sur la structure de liste en Python

Objectif

Revoir la structure de liste (parcours, construction, test d’appartenance) et la structure de tuple, qui permet de retourner plusieurs valeurs ou de représenter un point.

Sans exécuter le programme suivant, prévoir ce qu’il affiche, puis vérifier.

nombres = [4, 7, 1]
nombres.append(9)
print(len(nombres), nombres[1], nombres[-1])
Réponse

Le programme affiche 4 7 9. Après append, la liste vaut [4, 7, 1, 9] et contient 4 éléments. Les indices commencent à 0 : nombres[1] est le deuxième élément, 7. L’indice −1-1−1 désigne le dernier élément, 9.

Exercice 1

Écrire une fonction qui reçoit comme argument une liste de nombres à virgule et recherche lequel est le plus grand et lequel est le plus petit.

La spécification de la fonction est la suivante :

def minmax(liste: list[float]) -> tuple[float, float]:
    """
    Retourne un tuple constitué des valeurs minimale
    et maximale de la liste
    """
Solution 
def minmax(liste: list[float]) -> tuple[float, float]:
    """
    Retourne un tuple constitué des valeurs minimale
    et maximale de la liste
    """
    val_min = liste[0]
    val_max = liste[0]
    for valeur in liste[1:]:
        if valeur > val_max:
            val_max = valeur
        if valeur < val_min:
            val_min = valeur
    return val_min, val_max

Exercice 3

Écrire une fonction qui simule le tirage du Loto. Pour rappel, il s’agit de tirer aléatoirement 6 entiers compris entre 1 et 49.

Remarque. Un numéro ne peut apparaître qu’une seule fois. Il est donc nécessaire de stocker le résultat de chaque tirage dans une liste et de vérifier s’il est présent ou pas.

Coup de pouce

On ne sait pas combien de tirages seront nécessaires, puisqu’un numéro déjà sorti est rejeté : la boucle est une boucle while. Elle s’arrête quand la liste contient 6 numéros. L’opérateur in teste si une valeur est déjà dans la liste.

La spécification de la fonction est la suivante :

def loto() -> list[int]:
    """
    Simule le tirage du Loto. Retourne une liste de 6 entiers différents
    compris entre 1 et 49.
    """
Solution 
from random import randint


def loto() -> list[int]:
    """
    Simule le tirage du Loto. Retourne une liste de 6 entiers différents
    compris entre 1 et 49.
    """
    tirages: list[int] = []
    nbre_valeurs = 6
    while len(tirages) < nbre_valeurs:
        tirage = randint(1, 49)
        if tirage not in tirages:
            tirages.append(tirage)
    return tirages

Coup de pouce

Les trois intervalles se suivent sans se chevaucher et couvrent toutes les notes. Pour les deux premiers, on utilise nombre_dans_intervalle. Pour le dernier, fermé à droite, il suffit de retirer du nombre total de notes celles déjà comptées. Un pourcentage s’obtient en divisant par le nombre total de notes, puis en multipliant par 100.

Solution 
def moyenne(liste_notes: list[float]) -> float:
    """
    Détermine la moyenne des notes reçues en
    argument dans la liste passée en argument.
    """
    total = 0.0
    for note in liste_notes:
        total += note
    return total / len(liste_notes)


def nombre_dans_intervalle(
    liste: list[float], valeur_min: float, valeur_max: float
) -> int:
    """
    Détermine le nombre de valeurs de liste
    comprises dans l'intervalle [valeur_min, valeur_max[.
    """
    compteur = 0
    for valeur in liste:
        if valeur_min <= valeur < valeur_max:
            compteur += 1
    return compteur


def statistiques(notes: list[float]) -> tuple[float, float, float, float]:
    """
    Retourne la moyenne des notes (liste non vide) et les pourcentages
    de notes comprises dans les intervalles [0, moy - 3[,
    [moy - 3, moy + 3[ et [moy + 3, 20].

    >>> statistiques([12, 15, 8, 14, 6, 17])
    (12.0, 33.33333333333333, 33.33333333333333, 33.33333333333333)
    """
    moy = moyenne(notes)
    nbre_notes = len(notes)
    bas = nombre_dans_intervalle(notes, 0, moy - 3)
    milieu = nombre_dans_intervalle(notes, moy - 3, moy + 3)
    haut = nbre_notes - bas - milieu
    return (
        moy,
        bas / nbre_notes * 100,
        milieu / nbre_notes * 100,
        haut / nbre_notes * 100,
    )

Avec les notes de l’exemple, la moyenne vaut 12 : les intervalles sont [0,9[[0, 9[[0,9[, [9,15[[9, 15[[9,15[ et [15,20][15, 20][15,20]. On y trouve respectivement 8 et 6, puis 12 et 14, puis 15 et 17, soit deux notes sur six dans chacun.

Exercice 5

Écrire une fonction qui, à partir de deux points de l’espace à trois dimensions, calcule la distance euclidienne entre ces deux points. Remarque. Les coordonnées d’un point sont stockées dans un tuple.

La spécification de la fonction est :

def distance(
    pt1: tuple[float, float, float], pt2: tuple[float, float, float]
) -> float:
    """
    Détermine la distance entre les points pt1 et pt2.

    >>> distance((0, 0, 0), (1, 2, 2))
    3.0
    """
Solution 
from math import sqrt


def distance(
    pt1: tuple[float, float, float], pt2: tuple[float, float, float]
) -> float:
    """
    Détermine la distance entre les points pt1 et pt2.

    >>> distance((0, 0, 0), (1, 2, 2))
    3.0
    """
    x1, y1, z1 = pt1
    x2, y2, z2 = pt2
    return sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2 + (z2 - z1) ** 2)

Le déballage x1, y1, z1 = pt1 donne un nom à chaque coordonnée, ce qui rend la formule lisible.

Exercice 6

Reprendre l’exercice précédent et considérer que les points appartiennent à un espace de dimension NNN (NNN étant potentiellement grand). Si les deux points n’ont pas le même nombre de coordonnées, la fonction lève une erreur avec l’instruction raise ValueError("Les dimensions ne correspondent pas !").

La spécification de la fonction est :

def distance_n(pt1: tuple[float, ...], pt2: tuple[float, ...]) -> float:
    """
    Détermine la distance entre les points pt1 et pt2.
    Lève une erreur ValueError si les dimensions des tuples
    ne correspondent pas.
    """
Solution 
from math import sqrt


def distance_n(pt1: tuple[float, ...], pt2: tuple[float, ...]) -> float:
    """
    Détermine la distance entre les points pt1 et pt2.
    Lève une erreur ValueError si les dimensions des tuples
    ne correspondent pas.
    """
    if len(pt1) != len(pt2):
        raise ValueError("Les dimensions ne correspondent pas !")

    carre_distance: float = 0
    for x1, x2 in zip(pt1, pt2):
        carre_distance += (x2 - x1) ** 2

    return sqrt(carre_distance)

    Détermine la table de multiplication de tous les

    >>> table_multiplication(4)
    [[1, 2, 3, 4], [2, 4, 6, 8], [3, 6, 9, 12], [4, 8, 12, 16]]

Solution 
def table_multiplication(n: int) -> list[list[int]]:
    """
    Détermine la table de multiplication de tous les
    entiers compris entre 1 et n.

    >>> table_multiplication(4)
    [[1, 2, 3, 4], [2, 4, 6, 8], [3, 6, 9, 12], [4, 8, 12, 16]]
    """
    table: list[list[int]] = []
    for i in range(1, n + 1):
        ligne: list[int] = []
        for j in range(1, n + 1):
            ligne.append(i * j)
        table.append(ligne)
    return table

Révisions sur les structures de boucle en Python

Objectif

Revoir les deux structures de boucle de Python, la boucle bornée for et la boucle non bornée while, en écrivant des fonctions qui construisent une chaîne de caractères, dialoguent avec l’utilisateur ou calculent une suite.

Commençons par vérifier ce que fait exactement range. Sans exécuter le programme suivant, prévoir ce qu’il affiche, puis vérifier.

total = 0
for i in range(1, 5):
    total += i
print(total)
Réponse

Le programme affiche 10. range(1, 5) produit 1, 2, 3 et 4 : la borne de fin, 5, est exclue. On calcule donc 1+2+3+4=101 + 2 + 3 + 4 = 101+2+3+4=10, et non 1+2+3+4+5=151 + 2 + 3 + 4 + 5 = 151+2+3+4+5=15. Cette borne exclue est la source d’erreur la plus fréquente avec for : on la retrouvera dans presque tous les exercices.

Coup de pouce

Solution 
def table_multiplication() -> str:
    """
    Retourne la table de multiplication des nombres de 1 à 10.
    """
    chaine_retour = ""
    nbre_termes = 10

    for i in range(1, nbre_termes + 1):
        for j in range(1, nbre_termes + 1):
            chaine_retour += f"{i * j} "
        chaine_retour += "\n"

    return chaine_retour

Exercice 10

Modifier le programme précédent de façon à ce que l’utilisateur n’ait pas à indiquer le nombre de notes qu’il souhaite saisir. Une note négative termine la saisie.

Remarque : la fonction retourne le nombre de notes saisies et leur moyenne. Si aucune note n’a été saisie, elle retourne (0, 0.0).

Coup de pouce

On ne sait pas combien de notes seront saisies : la boucle est une boucle while. Que se passe-t-il si l’utilisateur entre tout de suite une note négative ? Penser à ce cas avant de calculer la moyenne.

Solution 
def moyenne_auto() -> tuple[int, float]:
    """
    Demande des notes à l'utilisateur tant que ce dernier
    ne rentre pas une note négative.
    Retourne le nombre de notes et la moyenne, ou (0, 0.0)
    si aucune note n'a été saisie.
    """
    nbre_notes = 0
    total_notes = 0.0
    stop = False
    while not stop:
        note = float(input(f"Entrez la note {nbre_notes + 1} : "))
        if note < 0:
            stop = True
        else:
            total_notes += note
            nbre_notes += 1
    if nbre_notes == 0:
        return (0, 0.0)
    return (nbre_notes, total_notes / nbre_notes)

Exercice 11

Écrire et exécuter une fonction qui simule un tirage du Loto.

Remarque. Normalement, lorsqu’un numéro est tiré, il ne peut pas apparaître à nouveau. On acceptera cependant qu’un même numéro puisse apparaitre plusieurs fois puisqu’on n’utilise pas encore de structure de données qui permette de « stocker » plusieurs valeurs : ce sera l’objet des révisions sur les listes.

Solution 
from random import randint


def loto_naif() -> str:
    """
    Retourne 6 entiers sélectionnés aléatoirement dans l'intervalle
    [1, 49].
    """
    nbre_valeurs = 6
    rep = ""
    for _ in range(nbre_valeurs):
        valeur = randint(1, 49)
        rep += f"{valeur} "
    return rep

Écrire et exécuter une fonction qui retourne l’alphabet à l’endroit si elle reçoit l’argument "croissant" ou à l’envers si elle reçoit l’argument "decroissant".

Remarque. On peut obtenir le code décimal d’un caractère à l’aide de la fonction ord. À l’opposé, le caractère correspondant à un entier naturel dans la table ASCII est obtenu (si possible) à l’aide de la fonction chr.

La spécification de la fonction est

    """
    Retourne les lettres de l'alphabet en fonction de la chaîne de caractères
    passée en argument.
    Les valeurs possibles pour cet argument sont 'croissant' ou 'decroissant'.

    Code ascii [97; 122]
    """
Solution 
def alphabet(sens: str) -> str:
    """
    Retourne les lettres de l'alphabet en fonction de la chaîne de caractères
    passée en argument.
    Les valeurs possibles pour cet argument sont 'croissant' ou 'decroissant'.

    Code ascii [97; 122]
    """
    if sens == "croissant":
        debut, fin, pas = ord("a"), ord("z") + 1, 1
    else:
        debut, fin, pas = ord("z"), ord("a") - 1, -1

    rep = ""
    for code in range(debut, fin, pas):
        rep += chr(code)
    return rep

Cette fonction doit recevoir en argument la valeur de nnn et retourner la suite de nombres sous forme de chaîne de caractères. Par exemple, fibo(8) retourne '1 1 2 3 5 8 13 21 '. Spécification de la fonction :

    """
Coup de pouce

Pour calculer un terme, il faut connaître les deux précédents. Utiliser deux variables u et v qui contiennent toujours deux termes consécutifs. À chaque tour, comment calculer les deux termes consécutifs suivants à partir de u et v ? L’affectation multiple u, v = ..., ... évite d’écraser une valeur dont on a encore besoin.

Solution 
def fibo(n: int) -> str:
    """
    Retourne les n premiers termes de la suite de Fibonacci.
    """
    rep = ""
    u, v = 1, 1  # u_1 et u_2
    for _ in range(n):
        rep += f"{u} "
        u, v = v, u + v
    return rep

Héron d'Alexandrie

Héron d’Alexandrie est un ingénieur, un mécanicien et un mathématicien grec du premier siècle après J.-C.

On ne sait pas grand chose de la vie d’Héron, si ce n’est qu’il était originaire d’Alexandrie ; les historiens se sont même longtemps divisés sur l’époque où il a vécu. Leurs estimations allaient du 1er siècle avant J.-C. au 3ème siècle de notre ère. Aujourd’hui, la querelle est éteinte : il est clairement établi que Héron est postérieur à Vitruve mort en −20- 20−20, et contemporain de Pline l’Ancien (23 – 79), en étant actif autour de l’an 62. Il a donc bien vécu au 1er siècle après J.-C. et sans doute au début du 2ème siècle, donc sous l’Empire romain, mais dans l’Alexandrie grecque.

On attribue à Héron d’Alexandrie plusieurs formules mathématiques et une méthode efficace d’extraction de racine carrée, c’est-à-dire de résolution de l’équation x2=ax^2 = ax2=a, avec aaa positif :

Info
  1. Choisir une première valeur raisonnable que l’on note GGG.
  2. Améliorer cette valeur en calculant la moyenne des valeurs GGG et a/Ga/Ga/G.
  3. Vérifier si cette nouvelle valeur convient.
  4. Reprendre l’étape 2 tant que la valeur calculée n’est pas satisfaisante.
Objectif

Programmer la méthode de Héron en la découpant en petites fonctions, chacune accompagnée de sa spécification et de ses tests.

Avant de programmer, faisons tourner la méthode à la main, pour voir comment elle se comporte.

Question. On cherche la racine carrée de a=2a = 2a=2 en partant de G=1G = 1G=1. Effectuer deux fois l’étape 2 de la méthode, à la main. Comparer le résultat à la valeur 2≈1,41421\sqrt{2} \approx \text{1,41421}2​≈1,41421.

Réponse
  • Première amélioration : la moyenne de 111 et de 2/1=22/1 = 22/1=2 vaut 1,5\text{1,5}1,5.
  • Deuxième amélioration : la moyenne de 1,5\text{1,5}1,5 et de 2/1,5≈1,333332/\text{1,5} \approx \text{1,33333}2/1,5≈1,33333 vaut environ 1,41667\text{1,41667}1,41667.

Après deux étapes seulement, le résultat est déjà correct à 0,003\text{0,003}0,003 près. On comprend pourquoi la méthode marche : si GGG est trop grand, a/Ga/Ga/G est trop petit, et inversement. La moyenne des deux tombe entre les deux, plus près de la racine.

Réponse
  • La documentation d’une fonction est le texte placé entre triples guillemets juste sous sa première ligne. Elle explique ce que fait la fonction, ce qu’elle attend et ce qu’elle retourne. Python la conserve : help(moyenne) l’affiche dans la console.

    """
